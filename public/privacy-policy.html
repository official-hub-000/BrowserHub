BrowserHub Privacy Policy

Effective Date: November 16, 2026

1. Zero Data Collection & Zero Telemetry

BrowserHub ("the App", package com.browserhub.app) does not collect, log, store on external servers, sell, or share any personal information, browsing history, search queries, IP addresses, device identifiers, or crash analytics. All tabs, bookmarks, passwords, and settings reside strictly locally on your Android device.

2. Android VpnService Disclosure

BrowserHub integrates Android's android.net.VpnService API solely to provide an optional, user-initiated encrypted privacy tunnel (WireGuard / DNS-over-HTTPS) that protects web traffic on public and untrusted networks. Before activating the VPN for the first time, BrowserHub displays an explicit in-app consent disclosure. No traffic payloads, DNS lookups, or source IP addresses are logged or monetized, and BrowserHub never redirects or manipulates traffic from other apps for advertising purposes.

3. Local On-Device AI & Translation

BrowserHub's summarization, Q&A copilot, and multi-language page translation features process webpage text locally without requiring third-party cloud API keys, user accounts, or external data storage.

4. Biometric Authentication

When Incognito Vault Biometric Lock is enabled, authentication is handled exclusively by Android's system BiometricPrompt hardware keystore. BrowserHub never accesses or stores raw biometric data.

5. Instant User Data Deletion

Users can permanently erase all local browsing data, cookies, cache, and storage at any time in one tap using the in-app Fire Wipe button or Android System Settings.

6. Contact

For privacy inquiries or open-source security audits, please open an issue on the official BrowserHub repository.
