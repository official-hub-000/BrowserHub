The copyright line and licence reference above are read directly from the
font's own `name` table (name IDs 0, 13 and 14) in oxanium.ttf, so they match
the file on disk exactly rather than being retyped from memory.

Why the full licence body is not reproduced here: it was not reachable from the
build environment (raw.githubusercontent.com and scripts.sil.org are both
routed out), and reproducing the OFL from memory risks a subtly wrong text,
which would be worse than an accurate reference. The canonical text at the URLs
above governs. If you need it vendored, drop the official OFL.txt beside this
file unchanged.
